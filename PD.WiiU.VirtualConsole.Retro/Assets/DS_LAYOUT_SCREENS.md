# ds_layout_screens.zip

MikaDubbz's extra screen layouts for the DS Virtual Console, as the previous application shipped them (`DSLayoutScreens.zip` from https://github.com/Hotbrawl20/UWUVCI-Tools, unmodified). 4,727,533 bytes, SHA-256 `f8e685e5afca769db1088ae316b70da08dc42b616316308fd52a344e5fa03cd3`. Community art; see https://gbatemp.net/threads/add-many-more-screen-layout-options-in-ds-virtual-console-games.574254/.

Two variants, each a `content/0010` tree copied over the base's: `All` for any game, `Phatnom Hourglass` (the folder name's typo is the original's) for games that want the touch screen on the TV. Each brings its own `configuration_cafe.json`; the brightness and upscaler settings are applied after it.
