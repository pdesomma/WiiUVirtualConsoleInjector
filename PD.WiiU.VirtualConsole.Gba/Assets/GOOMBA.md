# goomba.gba

Goomba Color, the Game Boy / Game Boy Color emulator for the Game Boy Advance, by Dwedit, built on Goomba by FluBBa. GPL.

This is the unmodified 2019-05-04 release from https://www.dwedit.org/gba/goombacolor.php (`goombacolor_2019_5_4.zip`, 76,020 bytes, SHA-256 `663eb808021b4d72…`); the matching source is `goombacolor_source_2019_5_4.zip` on the same page.

The injector prepends it to a Game Boy or Game Boy Color ROM so the GBA Virtual Console runs the game through Goomba. The previous application shipped a modified build (76,360 bytes) without source; `GbaRomInjector` accepts a path to any other build.
